# Contributing

- Keep the evaluator Python 3.9-compatible and free of runtime dependencies.
- Use synthetic or properly licensed benchmark records; label synthetic facts explicitly.
- Add tests for each new unit, failure code, or schema behavior.
- Do not loosen matching rules without documenting the false-positive tradeoff.
- Update the changelog and architecture notes for schema or scoring changes.
- Run `make test` before opening a pull request.

Never commit proprietary reports, credentials, personal information, or unlicensed datasets.
